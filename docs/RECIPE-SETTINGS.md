# Recipe and settings review

Affordable belt-matched recipes is optional and disabled by default. Every supported tier uses one matching transport belt, two basic inserters and two gears. No previous loader or underground belt is consumed. Matt's Ultimate loader therefore uses one Ultimate transport belt plus four basic components. Research dependencies remain unchanged. If a companion belt item is absent, retain that tier's original recipe.

Craft two loaders per batch (previously Double all Recipes) doubles ingredients AND output; it never discounted per-loader cost. Tested affordable recipes on nine tiers with single and double batches in Factorio 2.0.77.

Existing settings remain implemented: automatic snapping, default mode, chute, no power and spill/discard defaults. Automatic Speed Mode conversion is an explicit conversion of existing compatible loaders at configuration change, not a performance test. Legacy import only targets old Factorio 1.1 base-tier Miniloaders; ordinary Redux-to-fork adoption is automatic and does not need it. Debug logging remains off by default. The loader collision-mask sanitizer affects OTHER mods and the blueprint workaround destroys stray internal components; retain both as opt-in advanced troubleshooting switches, disabled by default.

Startup recipe changes require restart and matching multiplayer startup settings. Existing entities and inventory items are unaffected.
