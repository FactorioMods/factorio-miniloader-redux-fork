# Miniloader (Redux) Fork

Compact 1×1 loaders with fixes for connected rotation, belt snapping and robot-built rotated or mirrored blueprints.

**Factorio 2.1 · Version 1.0.5**

- Based on hgschmie’s Factorio 2.1 Miniloader Redux 2.2.5.
- Retains normal, speed and lane-filter modes, plus supported belt integrations.
- Connected rotation keeps the established axis; unconnected loaders rotate freely.

[Modes, filters, blueprints and troubleshooting](docs/USAGE.md).

## Installation

Disable miniloader-redux before enabling this fork. Existing loaders are adopted in place. Physical filters, modes, wires and stack settings are retained. The old mod’s private spill/discard preference falls back to this fork’s startup setting; the default spills items.
